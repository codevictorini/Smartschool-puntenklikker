Download PuntKlik

Installeer PuntKlik rechtstreeks via de Chrome Web Store. Handmatig installeren kan ook met de ZIP-download.

Installeren via Chrome Web Store

Voor handmatige installatie: download de extensiebestanden (.zip).

Je kunt de broncode bekijken op GitHub.

Installeren in Chrome

  1. Pak het gedownloade ZIP-bestand uit.
  2. Open chrome://extensions en zet Ontwikkelaarsmodus aan.
  3. Klik op Uitgepakte extensie laden en selecteer de uitgepakte PuntKlik-map met manifest.json.
  4. Open Smartschool en ga naar je resultaten.

Hulp nodig? Neem contact op.
